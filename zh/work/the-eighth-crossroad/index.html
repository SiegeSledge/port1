《第八次抉择》The Eighth Crossroad（第八次献祭）

围绕科技伦理与危机决策的双人非对称信息叙事游戏，从纸面原型迭代为双线 Twine 数字版。

概述

《第八次抉择》（也称《第八次献祭》）是一款关于科技伦理与危机决策的教育叙事游戏，由我在哥伦比亚大学师范学院作为团队项目开发，由 Dennis Morgan 教授指导。它同时有两种形态：桌游，以及 Twine 数字版。

设计

  • 桌游版与 Twine 版共用同一套核心叙事与三章伦理结构。
  • 双人之间的非对称信息，以及驱动协作的”阅读、沟通、决策、反思“循环。
  • Past / Future 双玩家双线叙事，并把碎片化叙事整合成完整的三章结构。

我的职责

  • 试玩引导，以及用于降低认知负荷的 UX 文案。
  • Twine 快速原型与数字版实现。
  • 用产品管理方法跟踪叙事、美术、音乐与代码进度。
  • 参与编程、关卡设计与 UI 设计，使用 Figma 与 Twine。

试玩与迭代

我组织了共 3 轮、48 名参与者的试玩，并完成 3 轮迭代，调整可复玩性、难度平衡、游戏时长，以及学习目标是否真的被传达。

成果

  • 发布至 itch.io，20+ 次下载。
  • 获校级二等奖与“最受欢迎奖”。
