TransitEase 无障碍交通应用

面向纽约地铁中残障、轮椅及大件行李出行人群的出行辅助应用，整合实时路况、无障碍导航与社区反馈。

负责人
时间

机构

概述

TransitEase 是一款面向纽约地铁中残障乘客、轮椅使用者和携带大件行李人群的应用，把实时路况、无障碍导航与社区反馈整合进同一个决策流程。这是我在 Ji Woo 教授指导下完成的独立项目，同一主题也是我上海纽约大学毕业论文的研究对象。

问题

选择纽约作为代表性的试验场有两个原因：MTA 的无障碍问题被广泛讨论，而且纽约交通有足够多的数据和既有研究。尽管有电梯等无障碍设施，残障乘客仍然从两端遇到困难：

  • 服务方（如 MTA）缺乏足够的无障碍基础设施，也无法收集无障碍设施是否可用的实时数据。
  • 用户方：地图软件依赖过时的无障碍设施与目的地信息，导致行程规划和路线建议不准确。

经历一次失败的迭代之后，最终思路依靠众包与通用设计。

研究

  • 案头研究与用户画像。
  • 在主要地铁站访谈 30+ 位残障人士，识别路线规划、设施状态与临时求助中的断点。

设计

  • 负责信息架构、关键用户流程与高保真原型：用 Axure RP 画用户流程，Figma 做线框和 UI。
  • 搭建可运行的原型：VS Code 写前端，MySQL 做后端数据库，Google Maps API 实现 GPS 与地图功能，把导航、设施信息与社区反馈整合在一起。
  • 增加内嵌地图的用户社区，并根据真实使用反馈调整信息优先级和任务流程。
  • 引入代币奖励机制以提升可持续使用，并探索与慈善组织合作的收入来源。

成果

  • 累计沉淀 200+ 深度使用用户，验证了无障碍导航与社区信息共享的真实需求。
  • 毕业论文：Community-based solution to disabled transportation: A community-based AI-empowered solution of routine planning for disabled people（上海纽约大学，2025 届）。关键词：crowd-sourcing、accessible design、universal design、route planning、real-time accessible data。
